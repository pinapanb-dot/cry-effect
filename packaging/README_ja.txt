Cry Effect(泣き声化ツール)
==========================

ボーカルの WAV の、指定した区間だけに「泣き」の特徴(震え、しゃくり上げ、声の裏返り など)を
加えるツールです。出力は元と同じ長さ・同じサンプルレートの 32bit float WAV で、元のファイルは
上書きしません。


動作環境
--------
- Windows 10 / 11(64bit)
- Microsoft Edge(Windows に標準で入っています)。なければ Google Chrome、どちらもなければ
  既定のブラウザで開きます。
- インターネット接続は不要です(すべてこの PC の中で動きます)。


起動
----
1. zip をすべて展開します(zip の中から直接は起動できません)。
2. CryEffect フォルダの CryEffect.exe をダブルクリックします。
   - 初回は「Windows によって PC が保護されました」と出ることがあります(署名のないアプリのため)。
     「詳細情報」→「実行」で起動できます。
3. ツールのウィンドウが開きます。ウィンドウを閉じるとツールも終わります。

右上の「日本語 / English」で表示言語を切り替えられます(次回も同じ言語で開きます)。


使い方
------
1. 「開く…」で WAV(44.1kHz / 48kHz、モノラルまたはステレオ)を選びます。
   初回は分析に少し時間がかかります(3 分の曲で 15 秒前後。2 回目からはすぐ開きます)。
2. 効果ごとのレーンの上をドラッグして区間を作ります(マーカーのレーンはダブルクリック)。
3. 区間をクリックすると、右側で強さとパラメータを調整できます。変更は自動で反映されます。
4. B キーで「元の音 / 処理あり」を聞き比べ、L キーで選択した区間をループ再生します。
5. 「保存」でプロジェクト(<WAV名>.cry.json)を保存、「WAV 書き出し…」で処理済み WAV を書き出します。

キー操作
  Space        再生 / 停止
  B            元の音 / 処理ありの切り替え
  L            選択区間をループ再生
  Delete       選択区間を削除
  Esc          選択解除
  Ctrl+ホイール 拡大・縮小      Shift+ホイール 横スクロール
  Ctrl+S       プロジェクトを保存


効果
----
  不規則な震え / 語尾の崩れ / 息っぽさ / むせび泣き(フォルマント低下) /
  嗚咽の脈動 / 声の裏返り(マーカー) / 発音の崩れ / しゃくり上げ /
  声の詰まり(マーカー) / F2 の上昇 / 鼻にかかる声 / 鼻をすする音などの素材

各効果の説明は、レーン名にマウスを乗せるか、区間を選ぶと右側に出ます。
「泣き度」スライダーで、すべての区間の効き具合をまとめて調整できます。


素材(吸気音・鼻をすする音など)
------------------------------
CryEffect フォルダの中の
  materials\inhale\   しゃくり上げ用の吸気音
  materials\sfx\      鼻をすする音などの効果音
に WAV を置くと、区間の「音源」で選べます。置かない場合は合成した音を使います。


データの保存場所
----------------
設定・分析キャッシュ・ログは次のフォルダに保存します。
  %LOCALAPPDATA%\CryEffect\
    settings.json   表示言語などの設定
    cache\          分析キャッシュ(3 分の曲で約 140MB。消しても構いません)
    logs\app.log    動作記録(うまく動かないときの調査用)
    window\         ツールのウィンドウ用のブラウザ設定

アンインストールは、CryEffect フォルダと上のフォルダを削除するだけです。


うまく動かないとき
------------------
- ウィンドウが開かない: 少し待ってから、もう一度 CryEffect.exe を起動してください。
  それでも開かない場合は logs\app.log を確認してください。
- ファイル選択の画面が見えない: ほかのウィンドウの後ろに出ていることがあります。
- 音が出ない: 「▶ 再生」を押してから数秒待ち、Windows の出力デバイスを確認してください。
